# تشغيل تطبيق المزرعة على أندرويد + مزامنة مع الكمبيوتر

## الملفات المطلوبة مع بعض
ارفع الملفات دي كلها في نفس المكان:

- `المزرعة_v10.5_pwa_sync.html`
- `manifest.json`
- `service-worker.js`
- `icon-192.png`
- `icon-512.png`

## التثبيت على أندرويد
لازم التطبيق يتفتح من رابط HTTPS، مش من ملف مباشر `file://`.

أسهل حل:
1. ارفع الملفات على Netlify أو GitHub Pages أو أي استضافة HTTPS.
2. افتح الرابط من Chrome على الموبايل.
3. من قائمة Chrome اختر **Install app** أو **Add to Home screen**.

## المزامنة بين الموبايل والكمبيوتر
المزامنة محتاجة Google Apps Script كرابط وسيط.

### خطوات عمل رابط المزامنة
1. افتح: https://script.google.com
2. اعمل مشروع جديد.
3. امسح أي كود موجود والصق محتوى ملف:
   `google_apps_script_sync.gs`
4. لو عايز رمز حماية، اكتب أي كلمة سر هنا داخل الكود:
   `FARM_SYNC_TOKEN = 'اكتب_رمز_هنا';`
   ولو مش عايز، سيبها فاضية.
5. اضغط **Deploy > New deployment**.
6. اختار **Web app**.
7. Execute as: **Me**.
8. Who has access: **Anyone**.
9. Deploy ووافق على الصلاحيات.
10. انسخ رابط Web app اللي آخره `/exec`.

### داخل تطبيق المزرعة
على الكمبيوتر والموبايل:
1. افتح التطبيق.
2. ادخل **الأدوات والنسخ**.
3. حط رابط Google Apps Script في خانة **رابط Google Apps Script للمزامنة**.
4. لو كتبت رمز في السكريبت، اكتبه في خانة **رمز حماية المزامنة**.
5. خلي **المزامنة التلقائية بعد الحفظ = مفعلة**.
6. اضغط **حفظ الإعدادات**.
7. اضغط **مزامنة الآن** أول مرة.

بعد كده:
- أي تسجيل على الموبايل بيتبعت للسحابة بعد الحفظ.
- الكمبيوتر يسحب آخر نسخة تلقائيًا كل دقيقة تقريبًا وهو مفتوح.
- تقدر تضغط **مزامنة الآن** لو عايز التحديث فورًا.

## ملاحظة مهمة عن التعارض
لو الموبايل والكمبيوتر اتعدلوا في نفس الوقت وهما Offline، آخر جهاز يعمل مزامنة هو اللي هيكسب.
للاستخدام الطبيعي: خليك فاتح النت واضغط مزامنة قبل الشغل لو اشتغلت على جهاز تاني.
